🃏 The Tarot Site — Explained Like You're 10

Last updated: 2026-09-24. Read this when something breaks or you forgot how it works.

The one-sentence version:

This is a fortune-telling website. A visitor types their birthday (and optionally birth time + city) and the site shows their tarot cards, numbers, zodiac signs — and how compatible they are with another person. It has no server and no database: everything is math done in the visitor's own browser.

1. How it works (the toy-box analogy)

Imagine the site is a board game in a box:

  • The box = the folder on your computer. Everything the game needs is inside it.
  • The rulebook = the code files (they say: "if birthday is X, card is Y").
  • The cards and pictures = image files (the pretty art).
  • The build = packing the box. One command squishes everything into a tidy dist folder.
  • The deploy folder (tarot-numerology-site/) = the packed box, ready to ship to any web host.

IMPORTANT: there is no internet magic during a reading. No accounts, no saving, no calls to other websites. A birthday goes in, cards come out — like a calculator.

4. The golden rules (⚠️ read these)

  1. Never edit tarot-numerology-site/ or app/dist/ by hand. They are rebuilt from the source. Hand-edits vanish on the next build.
  2. After any change, run REBUILD.bat (double-click). The site only shows what was packed last.
  3. The build is also a spell-checker. If you (or the AI) type something wrong in the data files, the build fails on purpose and shows the exact file and line. A red screen with an error is good news — it caught a typo before it reached visitors.
  4. One hidden trick keeps the astrology alive: in app/vite.config.ts there's an alias pointing the astrology library to its dist file. Never delete that alias or the Sky page breaks.
  5. Images keep their names. Replace the file, don't rename it. The code finds pictures by name.
  6. The site is English-only, by decision. City names may look Portuguese (Nápoles, Turim) — that's fine, they were added for you.

5. Everyday tasks (how do I…)

…change what a card or number means?

Open the matching file in app/src/lib/ (card meanings: tarot.ts; numbers: numerology.ts + numerologyParts.ts; signs/houses: astrology.ts), edit the text, run REBUILD.bat.

…swap a picture?

Save the new image with the exact same file name over the old one in app/public/journey/ or app/src/assets/cards/, then run REBUILD.bat.

…publish the site on the internet?

The site is not online yet. When you pick a host (Netlify, Cloudflare Pages, GitHub Pages…), just upload the contents of tarot-numerology-site/. There's nothing else to configure — no database, no keys, no server.

…see the site while working on it?

Run npm run dev in the project folder and open the local address it prints (port 7100).
